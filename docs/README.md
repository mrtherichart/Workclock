# WorkClock guide

A few common tasks, using the Android app.

1. [Get started](getting-started.md) — install, permissions and your first day.
2. [Save places](places.md) — home, work and location reminders.
3. [Record a day](workday.md) — start, finish, project and corrections.
4. [View your week](weeks.md) — a table for copying onto a work slip.
5. [Backups](backups.md) — keep a copy outside the app.

The screenshots use sample data from WorkClock's Linux test environment. Names, hours and distances are examples; the screens and buttons are from the Android app's interface.

For the source and build instructions, see [Building and testing](development.md).
